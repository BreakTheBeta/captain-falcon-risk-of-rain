# Gameplay showcase

`falcon-showcase.mp4` is a 1280×720, 60 fps gameplay demonstration of v0.4.9. The README embeds an animated excerpt of the new free-play section that opens the [GitHub Pages video player](https://breakthebeta.github.io/captain-falcon-risk-of-rain/media/); GitHub strips arbitrary HTML video tags from README content.

Recorded with keyboard input on a separate, silent virtual display. The first 19.3 seconds show complete Falcon Punch actions with imported Melee flames, short hops, then diagonal air dodges landing into wavedashes. A new 43.7-second continuous free-play section follows: running, jumps, aerials, jab combos, directional specials and a shield roll in Dried Lake. Total duration: 63 seconds. Gameplay runs at its recorded speed; the picture is enlarged to make Falcon visible. This is a movement demonstration, not a full combat or controller compatibility test.

Edited and exported using craftingApps’ headless FilmCraft workflow. Native editable framing, chapter graphics and short transitions are preserved in the local FilmCraft project; original captures are retained there. No separately distributed models, textures or sound files are included. Game imagery and audio belong to their respective owners; the project’s MIT license covers its code.

The cut plan and native finishing summary are recorded in [showcase-edit.json](showcase-edit.json).

Audio: captured game mix, without commentary or added music. Structural and decode checks do not establish subjective sound quality; continuous listening review remains pending.
